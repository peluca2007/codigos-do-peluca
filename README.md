# Códigos do Peluca

Exercícios de lógica de programação em C, feitos no início da graduação em Análise e Desenvolvimento de Sistemas (UTFPR).

## Conteúdo

| Arquivo | O que faz |
|---|---|
| `calculadora.c` | Calculadora de terminal com menu, validação de entrada e comando `/exit` |
| `sistema de médias.c` | Cadastra até 50 alunos, calcula a média de cada um e mostra a situação |
| `projeto simples de matriz.c` | Leitura e exibição de matrizes |
| `brincando com struct.c` | Uso de `struct` para agrupar dados |
| `média.js` | Página web com cálculo de média em JavaScript (abrir no navegador) |

## Conceitos praticados

- Laços, condicionais e funções
- Vetores, matrizes e `struct`
- Validação de entrada com `scanf`/`sscanf` e limpeza de buffer
- Strings com `string.h`

## Como executar

```bash
gcc calculadora.c -o calculadora -lm
./calculadora
```
